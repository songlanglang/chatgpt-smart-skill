# ChatGPT变聪明

ChatGPT/Codex 降智的诊断与应对技能。

解决三个问题：**怎么确认自己真的被降智了**、**怎么把智商找回来**、**没找回来的时候下一步查什么**。

## 能做什么

- **诊断第0步**：先确认你在用官方客户端和官方端点——中转站和镜像站的"变笨"是模型偷换，本文方法无效，这一步能省掉你后面全部白工
- **7 种诊断方法**：模型自报、果汁值、上下文长度、推理token指纹（有来源），知识日期、iPhone 测试、糖果测试（自拟辅助信号），每项都标了普通用户能不能真的测到
- **2 个核心解法**：
  1. **手机App「重新思考一遍」**——利用"上下文属于对话，模型属于请求"的机制错位，电脑攒上下文、手机要答案，不换网络不加钱
  2. **AGENTS.md 让 Codex 闭嘴**——绕过系统提示词里 30 秒进度汇报打断 512 token 翻页的问题，附完整的生效排查链
- **失效排查**：解法没效时，从文件路径到网络环境到任务基线的 5 步可执行排查顺序，而不是"厂商又改了规则"这种没法验证的归因

## 使用前提

不满足则方法不适用：付费订阅（**免费版分配小模型是产品分层，不是降智**）、官方客户端、手机 App（解法一）、AGENTS.md 写权限（解法二）。

## 怎么用

**最可靠的方式：自己读完 SKILL.md，手动执行。**

SKILL.md 是带 YAML frontmatter 的 agent 技能文件，要作为技能加载，需要支持 Skill 机制的客户端（如 Codex CLI）：放到 skills 目录，或让客户端读取本仓库。

把 GitHub 链接直接丢给普通 ChatGPT 对话不会自动执行——这需要该客户端有联网抓取 URL 的能力（普通 ChatGPT 默认没有）。

# ChatGPT变聪明

ChatGPT/Codex 降智的诊断与对抗技能。

## 核心内容

- **第一性原理**：降智 = 网络环境路由 + 思考预算削减 + 上下文截断，界面不可见
- **7 种诊断方法**：模型自报、知识日期、iPhone测试、糖果测试、果汁值、上下文长度、推理token指纹
- **3 大解法**：
  1. 手机App「重新思考一遍」法——利用「上下文属于对话，模型属于请求」的未绑定机制
  2. AGENTS.md让Codex闭嘴法——绕过30秒汇报打断512token翻页的bug
  3. 网络环境规避法
- **失效条件与边界**：只治请求级/思考级降智，不治代际退步和中转站模型偷换

## 使用方法

放置到 `~/.codex/skills/ChatGPT变聪明/` 即可被调用。

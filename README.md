## 内容结构

- **使用前提**：不满足则方法不适用（付费订阅 / 官方客户端 / 手机App / AGENTS.md 写权限）。**免费版不适用**——免费版分配小模型是产品分层，不是降智
- **诊断第0步**：先确认官方客户端和官方端点。是中转站就停止，本文方法无效
- **7 种诊断**：4 种有来源（模型自报、果汁值、上下文长度、推理token指纹）+ 3 种技能自拟的辅助信号（知识日期、iPhone、糖果）。自拟项不得单独作为判据
- **2 个核心解法**：手机App「重新思考一遍」法、AGENTS.md 让 Codex 闭嘴法（含生效排查链）
- **1 个偏方案**：网络环境规避——来源原话是"群里经常讨论的各种防降智偏方"，作者未复测
- **失效条件与边界**、**修复验收标准**、**怎么让模型真正读到本技能**

## 怎么用

**最可靠的方式：自己读完 SKILL.md，手动执行。**

把 GitHub 链接直接发给普通 ChatGPT 对话**大概率无效**——SKILL.md 是带 YAML frontmatter 的 agent 技能文件，不是聊天模型的操作手册；且这需要客户端有联网抓取 URL 的能力（普通 ChatGPT 默认没有）。

要真正作为技能加载，需要支持 Skill 机制的客户端（如 Codex CLI）：放到 skills 目录，或让客户端读取本仓库。
